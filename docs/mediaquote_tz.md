# MediaQuote CLI — Техническое задание> Этап 2 — Подготовка ТЗ совместно с ИИ (Claude) | Версия 1.0 | 2026---## 1. Описание проектаMediaQuote CLI — консольная утилита для поиска, просмотра и управления цитатами из трёх источников: высказывания известных людей, цитаты из фильмов, цитаты из видеоигр. Утилита объединяет данные нескольких открытых REST API в единый унифицированный формат, предоставляет локальное хранилище (SQLite) и богатый интерфейс командной строки на базе Typer + Rich.### 1.1 Единый формат цитатыВсе три источника приводятся к единой модели:| Поле          | Тип    | Описание                                              ||---------------|--------|-------------------------------------------------------|| `id`          | str    | Уникальный ID вида `zen_*`, `movie_*`, `game_*`, `local_*` || `content`     | str    | Текст цитаты                                          || `author`      | str    | Автор или персонаж                                    || `source`      | str    | Фильм / игра / произведение                           || `source_type` | str    | Тип: `person` \| `movie` \| `game`                   || `tags`        | list   | Теги (список строк)                                   || `api`         | str    | Источник: `zenquotes` \| `dataset` \| `local` |---## 2. Используемые API| Источник        | URL / описание              | Назначение                                                      ||-----------------|-----------------------------|-----------------------------------------------------------------|| ZenQuotes       | https://zenquotes.io/api        | Цитаты известных людей (внешний API, без ключа)   || Датасет фильмов | Встроенный (753 цитаты)         | Классические цитаты из кино                       || Датасет игр     | Встроенный (20 цитат)           | Цитаты из видеоигр                                || mediaquote-api  | http://localhost:8000           | Собственный FastAPI сервер для фильмов и игр      |Для команды `random` выбирается случайный источник из трёх. При недоступности ZenQuotes используется встроенный fallback-датасет из 20 цитат.---## 3. REST API EndpointsБазовый URL внешних API указан в разделе 2. Локальные операции работают с SQLite напрямую.| Метод    | Endpoint                        | Описание                                    ||----------|---------------------------------|---------------------------------------------|| GET      | `/quotes`                       | Список цитат с фильтрацией по автору, типу, источнику || GET      | `/quotes/{id}`                  | Конкретная цитата из локального хранилища по ID || POST     | `/quotes`                       | Сохранить цитату вручную в локальное хранилище || DELETE   | `/quotes/{id}`                  | Удалить цитату из локального хранилища      || GET      | `/quotes/random`                | Случайная цитата (объединяет все три API)   || GET      | `/quotes/export`                | Экспорт цитат из хранилища в CSV или JSON   || GET      | `/quotes/filter`                | Продвинутая фильтрация и сортировка         || GET      | `/quotes/game/{game_name}`      | Все цитаты из конкретной игры               || GET      | `/quotes/movie/{movie_name}`    | Все цитаты из конкретного фильма            || GET      | `/quotes/search`                | Поиск по ключевому слову (все источники)    || POST     | `/quotes/{id}/favorite`         | Добавить цитату в список избранного         || POST     | `/quotes/{id}/rate`             | Оценить цитату (1–5)                        || GET      | `/quotes/stats`                 | Статистика по всему цитатнику               |---## 4. Обработка ошибок| Ситуация               | Exit code | Поведение                                                          ||------------------------|-----------|--------------------------------------------------------------------|| Ресурс не найден       | 1         | Сообщение `[red]` + `raise typer.Exit(1)`                         || Сетевая ошибка API     | 2         | Предупреждение + использование fallback-данных (игры / фильмы)    || Неверные аргументы     | 2         | `typer.BadParameter` с понятным описанием                          || Ошибка хранилища       | 3         | Сообщение об ошибке SQLite + корректное завершение                 || Успешное выполнение    | 0         | Вывод данных в формате table / json / csv                          |---## 8. Конфигурация### Переменные окружения| Переменная             | По умолчанию | Описание                      ||------------------------|--------------|-------------------------------|| `MEDIAQUOTE_TIMEOUT`   | `10`         | Таймаут HTTP-запросов (сек)   || `MEDIAQUOTE_VERBOSE`   | `false`      | Включить подробный вывод      || `MEDIAQUOTE_PAGE_SIZE` | `20`         | Размер страницы при листании  || `MEDIAQUOTE_API_URL`   | `http://localhost:8000` | URL локального FastAPI сервера|### Локальный конфиг-файлПуть: `~/.mediaquote/config.json````json{  "timeout": 10,  "verbose": false,  "page_size": 20}```### База данныхПуть: `~/.mediaquote/quotes.db` (SQLite). Таблицы: `quotes`, `favorites`, `ratings`.---## 9. Логирование- Все статусные сообщения — через `rich.console` (зелёный = успех, жёлтый = предупреждение, красный = ошибка);- Режим verbose: подробные сообщения об HTTP-запросах и ответах API;- Индикаторы прогресса `console.status()` при запросах к внешним API;- Логов в файлы не ведётся (только консольный вывод).---## 11. Примеры использования```bash# Случайная цитата из любого источникаpython cli.py quotes random --save# Поиск по ключевому словуpython cli.py quotes search "war"# Все цитаты из Dark Soulspython cli.py games get "Dark Souls"# Все цитаты из Star Warspython cli.py movies get "Star Wars"# Добавить цитату вручнуюpython cli.py quotes add "Keep your friends close" --author "Corleone" --type movie# Добавить в избранное и оценитьpython cli.py favorites add game_gm009python cli.py rate set game_gm009 5# Экспорт в CSVpython cli.py export quotes --format csv --output my_quotes.csv# Статистикаpython cli.py stats show```---*ТЗ составлено совместно с Claude (Anthropic) в рамках учебного задания — Этап 2*
